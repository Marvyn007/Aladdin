## Design Context

### Users
Aladdin serves job seekers pursuing early-career software engineering roles, while the admin surface serves internal operators managing sourcing quality, moderation, user activation, and data collection. Admins need fast visibility into ingestion health, user behavior, and intervention points without leaving the dashboard.

### Brand Personality
Confident, helpful, and precise. The product should feel supportive to job seekers and controlled for internal operators. For the admin area specifically, the emotional target is calm authority rather than noisy "power user" theatrics.

### Aesthetic Direction
Use the `claude blu 2` theme from tweakcn for admin-only surfaces. The visual tone should be soft, professional, and data-rich: pale blue neutrals, restrained contrast, polished tables, layered cards, and a premium operational feel. Avoid generic SaaS dashboards, loud gradients, and anything that feels disconnected from serious data work.

### Design Principles
1. Keep admin styling route-scoped so the rest of the product remains untouched.
2. Make control surfaces feel trustworthy: strong hierarchy, clear actions, visible system status.
3. Design tables as decision tools, not plain data dumps.
4. Prefer calm polish over visual noise; use blue as structure, not decoration.
5. Add components that help admins collect, interpret, and act on user and source data faster.

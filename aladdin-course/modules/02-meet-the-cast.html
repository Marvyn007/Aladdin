The Shared Memory

All five components read from and write to one shared object called the Zustand store. Think of it as a whiteboard in the middle of the room — any component can write on it, any component can read from it.

CODE 

const useStore = create<AppState>()(
  persist(
    (set, get) => ({
      jobs: [],
      selectedJob: null,
      filters: {},
      setJobs: (jobs) => set({ jobs }),
      setSelectedJob: (job) =>
        set({ selectedJob: job }),
    }),
    { name: 'aladdin-store' }
  )
);
PLAIN ENGLISH

create<AppState>()() → Create a global store that any component can subscribe to — when it changes, every listening component re-renders automatically

persist(...) → Automatically save state to localStorage — so if you refresh the page, your selected job and filters are still there

jobs: [] → Start with an empty list of jobs (filled in when the page loads)

selectedJob: null → Nothing is selected yet — clicking a job card sets this

filters: {} → No filters applied yet

setJobs / setSelectedJob → Functions that components call to update the shared memory — like writing on the whiteboard

'aladdin-store' → The localStorage key used to save and restore this state

What is Zustand? "Zustand" is German for "state." A library built by the open-source community. "State" just means "the current values the UI needs to display." Managing it in one place means components never fall out of sync.

The API Routes — The Back Room

The UI components talk to the browser. API routes handle the real work: databases, AI calls, file storage.

GET /api/jobs Fetch jobs from the database, calculate match scores
POST /api/resume Accept a PDF upload, parse it into structured JSON
POST /api/generate-cover-letter-stream Stream an AI-written cover letter word by word — the text appears in real time like someone typing
POST /api/application Create or update a Kanban board card for tracking your application status
POST /api/import-job Manually import a job from a description or URL — parses the posting and adds it to your list
POST /api/cron/process-queue Background worker: dequeue and run a scheduled job task — keeps things moving without user interaction
What IS an API route? It's a URL that does server-side work instead of returning a web page. When a component calls fetch('/api/jobs'), Next.js runs the matching route file and returns data.

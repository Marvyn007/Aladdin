## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 500 (medium) | 1.4 |
| Heading | 16-20px | 600 (semibold) | 1.4 |
| Display | 24px | 700 (bold) | 1.3 |

**Job Description Typography (Priority):**
- Font: Inter (via font-display: swap or self-hosted)
- Body: 15px, line-height 1.7 (for readability like LinkedIn)
- Headings: 16-18px, font-weight 600
- Lists: 14px with proper indent

**Dark Mode:**
- Background: #191919
- Background secondary: #202020
- Surface: #252525
- Border: rgba(255, 255, 255, 0.09)
- Accent: #529cca

**Accent reserved for:**
- Primary CTA buttons (View Original, Apply)
- Active tab indicators
- Save/bookmark icons (filled state)
- Links in job descriptions

## Component Redesign Guidelines

### Job Listing Cards (JobList.tsx)

**Current Issues to Fix:**
- Cards look like "AI slop" - need professional polish
- Insufficient visual hierarchy
- Typography inconsistent

**Requirements:**
- Clean card design with subtle shadow on hover
- Clear company logo placeholder (initials with company color)
- Prominent job title (semibold, 14-15px)
- Company name with logo (14px)
- Location with icon (12px, secondary color)
- Posted date with "recent" indicator (12px)
- Save button prominent but not overwhelming
- Selection state clearly visible
- Hover state with subtle background change

### Job Detail View (JobDetail.tsx)

**Current Issues to Fix:**
- Description text needs better typography for readability
- Action buttons need clearer hierarchy
- Company info section needs polish

**Requirements:**
- Job title: 20px, bold, dark primary
- Company: 16px with logo, linkable to interview experiences
- Meta info (location, posted date): clearly styled
- Sticky action button bar with clear primary/secondary hierarchy:
  - Primary: "View Original" (accent color)
  - Secondary: Save, Generate Cover Letter, Tailor Resume, Applied?
- Job description: Inter font, 15px, 1.7 line-height, proper heading styling
- Source link at bottom with hostname displayed

### Dashboard Layout

**Requirements:**
- View tabs clearly indicate current view
- Job list width: ~380px on large screens, flexible on smaller
- Smooth transitions between list and detail

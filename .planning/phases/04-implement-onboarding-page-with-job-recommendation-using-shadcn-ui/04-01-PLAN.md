    Create a new file with a `computePreferenceScore` function that takes a `Job` and an `answersByKey: Record<string, OnboardingAnswerRecord>` and returns a number 0-100.

    Scoring weights (per D-06 signals):
    - `work_areas` (30pts): Check if any selected role family label (lowercased, underscores to spaces, drop "engineer" suffix) appears in `job.title?.toLowerCase()`. Award 30 if any match.
    - `regions` (25pts): Check if any selected region label (underscores to spaces) appears in `job.location?.toLowerCase()`. Special case: `remote_worldwide` matches if location contains "remote". Award 25 if any match.
    - `role_types` (20pts): Check if any selected role type matches `job.jobType`. Map: `full_time` -> `fulltime`, `part_time` -> `parttime`, `contract` -> `contract`, `internship` -> `internship`, `freelance` -> `contract`. Award 20 if match.
    - `work_style` (15pts): If `flexible`, always award 15. Otherwise check: `remote` matches `job.isRemote === true`, `onsite` matches `job.isRemote === false`, `hybrid` matches if `job.location?.toLowerCase()` contains "hybrid". Award 15 if match.
    - `career_levels` (10pts): Check job.title against seniority keywords. Map: `early_career` -> ['junior','entry','intern','associate'], `mid_level` -> ['mid','ii','iii'], `senior_manager` -> ['senior','staff','lead','principal','manager'], `executive_leadership` -> ['director','vp','head','chief','executive']. Award 10 if any match.
    - `visa_sponsorship`: No positive points. If user selected 'yes' (needs sponsorship) and `job.title + job.location` does not contain 'visa' or 'sponsor', subtract 0 (soft signal - no penalty in v1 to keep things simple).

    Final: `return Math.min(100, Math.max(0, score));`
